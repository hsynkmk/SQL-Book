# Module 01 — Querying Basics

> Reading data is 80% of what most people do with SQL. Master the fundamentals here.

`SELECT` is the heart of SQL. This module takes you from "get some rows" to confident joins,
aggregation, subqueries, and pagination — noting where SQL Server and PostgreSQL differ (and they
differ most in **functions** and **paging**).

## Contents

| # | Topic | One-liner |
|---|-------|-----------|
| 01 | [SELECT, WHERE, ORDER BY](01.SELECT-WHERE-ORDER-BY.md) | Projecting, filtering, sorting |
| 02 | [Working with NULL](02.Working-with-NULL.md) | Three-valued logic, the #1 beginner trap |
| 03 | [Joins](03.Joins.md) | INNER/LEFT/RIGHT/FULL/CROSS/self |
| 04 | [Aggregation: GROUP BY & HAVING](04.Aggregation-GroupBy-Having.md) | SUM/COUNT/AVG, grouping, filtering groups |
| 05 | [Subqueries](05.Subqueries.md) | Scalar, correlated, EXISTS/IN |
| 06 | [Set Operations](06.Set-Operations.md) | UNION/INTERSECT/EXCEPT |
| 07 | [Built-in Functions](07.Built-in-Functions.md) | String/date/numeric/convert — big 🟦/🐘 differences |
| 08 | [Pagination](08.Pagination.md) | OFFSET/FETCH vs LIMIT, keyset paging |

## After this module you can

- Write correct, readable `SELECT` queries with joins and aggregation.
- Handle `NULL` without getting wrong results.
- Translate string/date functions between SQL Server and PostgreSQL.
- Paginate efficiently in either engine.
